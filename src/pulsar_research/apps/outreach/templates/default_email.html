{# PULSAR email theme. Deliberately almost nothing. An earlier version wrapped the message in a rounded white card on a grey page in a serif face, which looked like a newsletter, and — because the body was a stack of styled blocks — pasted into a reply as a mess. A cold academic email should paste cleanly and read like mail, so the body here is plain paragraphs in the reader's own default size, with no background, no border and no table around it. There is no footer card any more either. It carried corpus counts, a retrieval MRR and per-facet percentile bars, which is telemetry: it told the recipient where he ranked, and implied the sender was scoring professors against one another. The evaluation is in the attached report. Inline CSS only: Gmail and Outlook strip
